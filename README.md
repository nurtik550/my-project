# My Project

## Запуск проекта

1. Создайте виртуальное окружение:
   `python -m venv venv`
2. Активируйте его.
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Запустите программу:
   `python main.py`

## Ответы на вопросы

- **Зачем нужно виртуальное окружение (venv)?** Оно изолирует зависимости проекта от других Python-проектов.
- **Для чего нужен requirements.txt?** В нём записывают зависимости проекта, чтобы их можно было установить командой `pip install -r requirements.txt`.
